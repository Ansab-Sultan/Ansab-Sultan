## 🚀 Featured Projects

### 🔬 [Deep Research Agent](https://github.com/Ansab-Sultan/Deep-Research-Agent)
> AI-powered research assistant that conducts comprehensive, multi-step investigations autonomously.

An open-source agent that performs iterative, deep web and document research using LangGraph orchestration, Qdrant-powered RAG, and a modern Next.js frontend. Designed for async-first, scalable workloads with FastAPI, Redis, and Motor (MongoDB).

`LangGraph` `FastAPI` `Qdrant` `Next.js` `Redis` `MongoDB` `Tavily API`

---

### 🕸️ [Story Graph RAG](https://github.com/Ansab-Sultan/Story-Graph-RAG)
> Knowledge graph extraction and graph-powered Q&A over unstructured narrative text.

Transforms raw story content into an interactive knowledge graph (Neo4j) with hybrid retrieval via Qdrant. Features an agentic LangGraph Q&A layer and a rich Sigma.js-driven graph visualization frontend built with Next.js.

`LangGraph` `Neo4j` `Qdrant` `FastAPI` `Next.js` `Redis` `MongoDB`
